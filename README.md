# 🏛️ Finca M&M Booking System

## Project Structure

```
finca-mm/
├── React Native/   → Expo mobile/web app
└── api/            → Express.js backend API
```

## Running

### API (Terminal 1)
```bash
cd api
npm install
npm run dev
```
- API: http://localhost:3000
- Live Dashboard: http://localhost:3000/dashboard
- API Docs: http://localhost:3000/docs

### React Native App (Terminal 2)
```bash
cd "React Native"
npm install
npm start
```
